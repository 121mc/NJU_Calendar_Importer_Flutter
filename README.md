# 呢喃课表导入（Android / iOS）

一个使用 Flutter 开发的南京大学课表导入工具。应用通过南京大学官方统一身份认证获取课程和考试安排，并将所选学期日程写入手机系统日历。

当前版本：`1.6.1`

- Android：[下载地址](https://box.nju.edu.cn/d/adf190c64ece4373bf43/)
- iOS：在 App Store 搜索“呢喃课表导入”
- HarmonyOS：[NJU_Calendar_Importer_ArkTS](https://github.com/121mc/NJU_Calendar_Importer_ArkTS)
- 隐私政策：[NJU_Calendar_Importer_Privacy](https://github.com/121mc/NJU_Calendar_Importer_Privacy)

## 功能特性

- 支持本科生和研究生账号。
- 支持在主界面拉取学期信息，无需跳转登录页面。
- 支持 WebView 自动登录：
  - 自动填写已保存的学号和密码；
  - 填写凭据后自动点击官方登录按钮；
  - 在本地分析随后出现的滑块验证码并模拟滑动。
- 自动登录失败后可切换至手动登录：
  - 自动填写学号和密码；
  - 不自动填写验证码；
  - 不自动点击提交。
- 登录异常会区分网络连接失败、账号或密码错误、连续两次滑块失败等情况。
- 登录信息未发生变化时保留当前登录态；修改学号或密码后清除原登录态。
- 本科生可选择官方系统提供的不同学期，并同时获取课程和期末考试安排。
- 支持选择目标系统日历并写入课程、考试事件。
- 支持覆盖当前学期由本应用此前导入的旧事件。
- 支持删除目标日历中当前学期由本应用导入的日程，不影响其他学期的新格式事件。
- 兼容旧版本未记录学期标识的导入事件。

## 使用方法

1. 首次启动时阅读并同意隐私政策。
2. 点击“配置登录信息”，保存统一身份认证学号和密码。
3. 点击“拉取学期信息”。
4. 自动登录成功后，在主界面选择学期。
5. 点击“拉取所选学期课表”。
6. 加载手机系统日历并选择目标日历。
7. 按需选择覆盖旧事件，然后点击“写入系统日历”。
8. 如需清理，可在同一同步卡片中删除当前学期由本应用导入的日程。

如果自动登录连续两次无法通过滑块验证，可在提示框中点击“手动登录”。手动登录页会填写已保存的学号和密码，验证码和提交操作需要自行完成。

## 自动登录与失败处理

- 学校网页主页面加载超过 5 秒：提示检查网络连接。
- 滑块验证已通过但仍停留在登录页：停止继续滑动，并提示账号或密码有误。
- 连续两次滑块验证均失败：停止自动登录并提供手动登录入口。
- 自动登录长时间没有完成：提示自动登录失败。

自动登录依赖南京大学官方页面结构。学校调整认证流程、验证码实现或页面脚本后，相关功能可能需要重新适配。

## 权限与本地数据

- **网络权限**：访问南京大学统一认证、网上办事服务大厅及课表接口。
- **日历读取权限**：加载可用日历并识别本应用此前写入的事件。
- **日历写入权限**：向用户选择的系统日历写入课程和考试安排。

本应用不会主动读取通讯录。系统日历中的事件可能由 iCloud、Google、Exchange 等账户同步，该同步由操作系统和对应服务商控制。

本地保存内容主要包括：

- 自动登录学号和密码；
- 登录 Cookie 和会话信息；
- 隐私政策同意状态。

修改已保存的学号或密码会清除原登录态；内容未变化则不会清除。若要删除本地凭据和登录状态，可在系统设置中清除本应用数据。

## 开发环境

本项目使用 [FVM](https://fvm.app/) 管理 Flutter SDK，版本由仓库根目录的 `.fvmrc` 固定：

- Flutter：`3.47.2`（stable）
- Dart：`3.13.2`（随上述 Flutter SDK 提供）

克隆项目并安装 FVM 后，在项目根目录执行：

```bash
fvm install
fvm flutter --version
fvm flutter pub get
```

`.fvmrc` 需要纳入版本控制；`.fvm/` 是本机生成的 SDK 链接和缓存目录，不应提交。

VS Code 通常会由 FVM 自动配置项目 SDK。Android Studio 用户需要在 Flutter SDK 设置中选择项目下的 `.fvm/flutter_sdk`。若 IDE 已经打开项目，请在切换 SDK 后重新加载窗口或重启 IDE。
