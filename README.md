# 呢喃课表导入 for Android and iOS

一个基于 Flutter 开发的南京大学课表导入工具，可将本科生或研究生课表写入手机系统日历。

当前版本：1.4.0

## 下载

- iOS 下载方式：在 App Store 搜索“呢喃课表导入”
- HarmonyOS 版本：https://github.com/121mc/NJU_Calendar_Importer_ArkTS

## 项目说明

本项目通过南京大学官方统一认证网页完成登录，在本地拉取课表数据，并将课程与考试事件写入系统日历，方便在原生日历中统一查看和管理。

项目完全免费开源，不包含广告或内购。应用不会把账号、课表内容或日历数据上传到开发者自建服务器；相关数据仅在设备本地处理，并仅在访问官方系统时与学校服务器通信。

本项目由 **mc_121** 维护，欢迎通过 GitHub Issues 提出建议或反馈问题。项目与任何学校官方机构无关。

## 功能特性

- 支持本科生和研究生网页登录统一认证
- 本科生支持从官方学期列表中选择要导入的学期
- 本科生支持同时导入课程与期末考试安排
- 研究生保留当前学期课表导入流程
- 支持选择目标系统日历并写入课程/考试事件
- 支持按所选学期覆盖删除本应用此前导入的同学期事件
- 兼容旧版本导入标记，避免升级后旧事件无法清理
- 提供独立的“删除本软件生成的日程”页面，可按学期分组删除或全部删除本应用生成的事件

## 使用方法

1. 打开应用，阅读并同意隐私政策。
2. 选择本科生或研究生身份，并通过官方统一认证网页登录。
3. 本科生登录后，在“课表学期”中选择要导入的学期，再点击“拉取所选学期课表”。
4. 课表获取成功后，点击“加载手机日历”，选择要写入的目标日历。
5. 根据需要开启或关闭“覆盖删除本应用此前导入的旧事件”，然后点击“写入系统日历”。
6. 如需清理旧数据，可在底部“删除本软件生成的日程”入口中扫描并删除指定学期或全部由本应用生成的日程。

## 权限说明

本应用需要以下权限：

- 网络权限：用于访问统一认证和课表接口。
- 日历权限：用于读取系统日历列表、写入课表事件，以及删除本应用此前导入的事件。

如果系统只授予写入级日历权限，应用可以写入新事件，但无法读取和清理旧事件；请在系统设置中授予完整日历权限后再使用覆盖删除或清理功能。

## 开发与构建

```bash
flutter pub get
flutter test
flutter build apk --debug
```

构建完成后，Android debug APK 默认位于：

```text
build/app/outputs/flutter-apk/app-debug.apk
```

如需构建 release APK，请先配置 `android/key.properties` 和对应 keystore，然后执行：

```bash
flutter build apk --release
```

release APK 默认位于：

```text
build/app/outputs/flutter-apk/app-release.apk
```
