# 南京大学本科课表字段开发说明

本文档说明南京大学“我的课表”页面在所有学期中包含哪些字段，以及程序应如何读取、规范化和使用它们。本文档不记录完整的个人课表，只保留说明字段格式所需的单字段真实样例。

## 数据来源

本科课表使用两个课程接口：结构化上课安排来自：

```text
POST https://ehallapp.nju.edu.cn/jwapp/sys/wdkb/modules/xskcb/cxxszhxqkb.do
```

请求体使用表单编码：

```text
XNXQDM=<学期编号>
pageSize=9999
pageNumber=1
```

课程数组通常位于：

```text
datas.cxxszhxqkb.rows
```

页面课程列表（包括“其他信息”列）来自：

```text
POST https://ehallapp.nju.edu.cn/jwapp/sys/wdkb/modules/xskcb/cxxskclb.do
```

课程列表数组通常位于：

```text
datas.cxxskclb.rows
```

接口需要有效的南京大学登录会话。若响应是 HTML 而不是 JSON，通常表示登录态失效、进入了认证页面或发生了重定向。

## 页面展示字段

“我的课表”列表按以下顺序展示字段。示例取自页面中的真实非空值，但来自不同课程记录，仅用于展示格式，不能横向拼接成一门课程：

| 字段 | 真实例子 | 是否属于课程数据 | 建议用途 | 空值处理 |
| --- | --- | --- | --- | --- |
| 操作 | `大纲周历、联系方式` | 否 | “退课”“大纲周历”“联系方式”等页面按钮 | 不要存入课程模型 |
| 课程号 | `00010011B` | 是 | 识别课程，可作为去重键的一部分 | 保留为空，不要用课程名伪造 |
| 教学班名称 | `微积分II(第一层次)10班` | 是 | 区分同一课程的不同教学班 | 缺失时可回退到课程名称用于显示 |
| 开课单位 | `数学学院` | 是 | 展示院系或按院系筛选 | 可空 |
| 教师 | `侯飞` | 是 | 日历描述、搜索和展示 | 可空；多位教师应保存为数组 |
| 学分 | `5` | 是 | 展示和统计 | 解析为小数，不要解析为整数 |
| 时间地点 | `周二 5-6节 1-16周 馆3-101,周二 3-4节 1-16周 馆3-101,周四 7-8节 1-16周 馆3-101` | 是 | 生成为每周课程事件 | 必须进一步拆成上课周、星期、节次和地点 |
| 选课类型 | `指选` | 是 | 展示“指选”“自选”“跨专业”等分类 | 建议保存原始文本，避免枚举遗漏新类型 |
| 上课说明 | `本课程的慕课目前已经全部在中国大学慕课网上线，新一期慕课3月2日开课。` | 是 | 写入日历备注或课前提示 | 可空 |
| 后续调课信息 | `【调课】(第3周 周三 7-8节 教105) 临时调整教室为(新教207)` | 是 | 处理停课、补课、换教室等例外 | 可空；不能只当普通备注忽略 |
| 期末考试信息 | `时间：2026-06-22 10:30-12:30 地点：馆1-105` | 是 | 创建考试事件或给出提示 | 可空；推荐优先使用独立考试接口 |
| 其他信息 | `【期中考试】：</br>时间：2026-04-25 10:30-12:30</br>地点：馆1-304` | 是 | 保存系统尚未分类的补充内容；当前已观察到期中考试信息会放在此列 | 可空；应先保留原文，再识别已知事件类型 |

## 接口中的结构化字段

页面把时间和地点拼成了一段文本，但课程接口会返回更适合程序处理的结构化字段。本项目当前实际使用以下字段：

| 接口字段 | 含义 | 类型或格式 | 使用方法 |
| --- | --- | --- | --- |
| `KCM` | 课程名称 | 字符串 | 作为日历事件标题 |
| `KSJC` | 开始节次 | 整数 | 映射到该节课的开始时间 |
| `JSJC` | 结束节次 | 整数 | 映射到该节课的结束时间 |
| `SKXQ` | 上课星期 | 整数，通常为 1 至 7 | 1 表示周一，依次类推 |
| `SKZC` | 上课周位图 | 由 `0` 和 `1` 组成的字符串 | 第一个字符对应第 1 周；`1` 表示该周上课 |
| `JASMC` | 教室名称 | 字符串 | 作为日历地点 |
| `JSHS` | 教师信息 | 字符串 | 优先作为教师字段；内容可能包含附加联系方式 |
| `SKJS` | 上课教师 | 字符串 | `JSHS` 为空时的教师字段回退值 |
| `JXBMC` | 教学班名称 | 字符串 | 写入描述，或用于区分同名课程 |
| `SKBJ` | 上课班级 | 字符串 | 写入日历描述 |
| `XXXQDM_DISPLAY` | 校区名称 | 字符串 | 可用于展示或楼栋识别，不写入日历地点 |

接口可能继续返回课程号、开课单位、学分、选课类型和说明等字段。由于后端字段名可能随接口版本变化，代码应保留原始行，并在实际响应中确认键名后再建立映射，不应仅凭中文列名猜测接口键名。

## “其他信息”中的期中考试

浏览器“我的课表”页面中已观察到期中考试信息出现在“其他信息”列，而不是“期末考试信息”列。该字段结构适用于所有学期；上方字段表保留一条真实样例，下面使用占位符概括其通用结构：

```text
【期中考试】：</br>时间：<YYYY-MM-DD> <HH:mm>-<HH:mm></br>地点：<地点>
```

当前观察到的模式为：

```text
【期中考试】：<换行>时间：<YYYY-MM-DD> <HH:mm>-<HH:mm><换行>地点：<自由文本>
```

其中 `<换行>` 在接口或页面原始值中可能表现为字面量 `</br>`、`<br>`、`<br/>`、真实换行或它们的组合。`</br>` 虽然不是推荐的 HTML 写法，但实际数据中确实会出现，解析时必须兼容，不能只处理 `<br>`。

建议先规范化换行，再逐行识别标签：

```dart
String normalizeOtherInfo(Object? value) {
  return '${value ?? ''}'
      .replaceAll(
        RegExp(r'</?br\s*/?>', caseSensitive: false),
        '\n',
      )
      .replaceAll('\r\n', '\n')
      .trim();
}

class MidtermExam {
  const MidtermExam({
    required this.date,
    required this.startTime,
    required this.endTime,
    required this.location,
    required this.rawText,
  });

  final DateTime date;
  final String startTime;
  final String endTime;
  final String? location;
  final String rawText;
}
```

解析时还应遵守以下原则：

- 只有明确出现 `【期中考试】` 标签时才按期中考试处理，不要把“其他信息”中的任意日期误判为考试。
- 日期、开始时间和结束时间解析成功后才能创建日历事件；地点可以为空或为自由文本。
- 不要把期中考试写入 `finalExamInfo`；可以从 `otherInfo` 派生独立的 `MidtermExam`，同时保留完整 `rawText`。
- 若格式不完整或出现未知标签，应保留原始“其他信息”，并跳过结构化考试事件，而不是让整门课程导入失败。
- 页面上只有一个样例并不代表每门课程只有一次期中考试；内部模型宜使用列表以便向前兼容。

## 推荐的规范化模型

不要让界面字段或接口缩写直接扩散到业务代码。先把每一行转换成稳定的内部模型：

```dart
class CourseRecord {
  const CourseRecord({
    required this.courseCode,
    required this.courseName,
    required this.teachingClassName,
    required this.offeringUnit,
    required this.teachers,
    required this.credits,
    required this.meetings,
    required this.selectionType,
    required this.classNote,
    required this.adjustmentInfo,
    required this.finalExamInfo,
    required this.otherInfo,
    required this.midtermExams,
  });

  final String? courseCode;
  final String courseName;
  final String? teachingClassName;
  final String? offeringUnit;
  final List<String> teachers;
  final double? credits;
  final List<CourseMeeting> meetings;
  final String? selectionType;
  final String? classNote;
  final String? adjustmentInfo;
  final String? finalExamInfo;
  final String? otherInfo;
  final List<MidtermExam> midtermExams;
}

class CourseMeeting {
  const CourseMeeting({
    required this.weekday,
    required this.startPeriod,
    required this.endPeriod,
    required this.weeks,
    required this.location,
  });

  final int weekday;
  final int startPeriod;
  final int endPeriod;
  final List<int> weeks;
  final String? location;
}
```

一个课程可能有多组上课安排，例如周一和周三节次不同，或者单双周教室不同。因此 `meetings` 必须是列表，不能只在课程上保存一组星期、节次和地点。

## 从接口行生成上课安排

以下代码展示 `SKZC` 周位图的核心处理方式：

```dart
List<int> parseWeeks(Object? value) {
  final bitmap = '${value ?? ''}';
  return [
    for (var index = 0; index < bitmap.length; index++)
      if (bitmap[index] == '1') index + 1,
  ];
}

CourseMeeting? parseMeeting(Map<String, dynamic> row) {
  final startPeriod = int.tryParse('${row['KSJC'] ?? ''}');
  final endPeriod = int.tryParse('${row['JSJC'] ?? ''}');
  final weekday = int.tryParse('${row['SKXQ'] ?? ''}');

  if (startPeriod == null ||
      endPeriod == null ||
      weekday == null ||
      startPeriod <= 0 ||
      endPeriod < startPeriod ||
      weekday < 1 ||
      weekday > 7) {
    return null;
  }

  return CourseMeeting(
    weekday: weekday,
    startPeriod: startPeriod,
    endPeriod: endPeriod,
    weeks: parseWeeks(row['SKZC']),
    location: nullableText(row['JASMC']),
  );
}

String? nullableText(Object? value) {
  final text = '${value ?? ''}'.trim();
  return text.isEmpty ? null : text;
}
```

课程日期的计算公式为：

```text
上课日期 = 学期第一周周一 + (周次 - 1) × 7天 + (星期 - 1)天
```

必须先确认传入的学期起始日期已经归一化为第一周周一，否则所有事件都会产生固定的星期偏移。

## 从页面表格读取展示字段

只有在无法调用结构化接口时，才应从页面 DOM 读取列表。可以使用固定的列名建立映射，而不是依赖 CSS 类名：

```javascript
const fieldNames = [
  '操作',
  '课程号',
  '教学班名称',
  '开课单位',
  '教师',
  '学分',
  '时间地点',
  '选课类型',
  '上课说明',
  '后续调课信息',
  '期末考试信息',
  '其他信息',
];

const records = [...document.querySelectorAll('table tr')]
  .map((row) => [...row.querySelectorAll('td')]
    .map((cell) => cell.innerText.trim()))
  .filter((cells) => cells.length === fieldNames.length)
  .map((cells) => Object.fromEntries(
    fieldNames.map((name, index) => [name, cells[index] || null]),
  ));
```

DOM 方案得到的“时间地点”是展示文本。若要导入日历，仍需解析成多组 `CourseMeeting`。解析时应支持：

- 同一单元格中以逗号分隔的多组安排；
- `1-18周`、`2周` 和不连续周次；
- `单`、`双` 周限制；
- 教室名称中本身包含顿号、逗号或数字；
- 字段为空、换行或包含额外空格；
- 页面增加新列或调整列顺序。

由于地点也可能包含逗号，不能简单地对整段文本执行 `split(',')`。优先依据“周几 + 节次 + 周次”模式识别每组安排的开头，再把下一组安排之前的文本视为地点。

## 不同字段如何进入日历

| 日历属性 | 推荐来源 | 说明 |
| --- | --- | --- |
| 标题 | `KCM` | 不建议直接使用带班号的教学班名称代替课程名称 |
| 开始和结束时间 | `KSJC`、`JSJC` | 通过学校节次时间表转换为具体时间 |
| 重复日期 | `SKXQ`、`SKZC` | 可以展开成每周独立事件，便于处理调课和停课 |
| 地点 | `JASMC` | 只写教室字段，不添加“南大”或校区前缀；空值保持为空 |
| 描述 | 教师、教学班、上课班级、选课类型、上课说明 | 只拼接非空字段 |
| 例外事件 | 后续调课信息 | 停课应删除或跳过对应周事件；补课应新增事件；换教室应覆盖对应周地点 |
| 考试事件 | 独立考试接口 | 页面“期末考试信息”适合展示，结构化考试接口更适合生成事件 |
| 期中考试事件 | `其他信息` 中的 `【期中考试】` | 规范化 `<br>`/`</br>` 后解析日期、起止时间和地点；保留原始文本 |
| 去重键 | 学期、课程标识、开始时间、结束时间、地点 | 不要只用课程名称，否则同名课程或不同周事件会冲突 |

## 健壮性要求

- 所有非关键文本字段都应允许为空。
- 学分使用 `double.tryParse`，因为可能出现小数学分。
- 节次、星期和周位图解析失败时，应跳过该条上课安排并记录可诊断日志，不要让整个学期导入失败。
- 不要把 `操作` 列中的按钮文字当成课程状态。
- 不要假设教师只有一人；展示文本可以用顿号连接，模型中建议保留列表。
- 不要假设一门课只有一个地点或一种上课周期。
- 不要假设考试只会出现在“期末考试信息”列；期中考试可能位于“其他信息”列。
- “其他信息”中的 HTML 换行标签可能以字面文本返回，应在解析前规范化。
- 保留原始接口行用于调试，但日志中不要输出学号、联系方式、登录 Cookie 或完整个人课表。
- 对未知选课类型和新增字段使用向前兼容策略：保留原文，避免直接抛错。
- 页面展示字段适合人工阅读；日历计算应优先使用接口中的结构化字段。

## 最小测试清单

代码至少应覆盖以下情况：

1. 正常的连续周课程。
2. 只在单周或双周上课的课程。
3. 不连续周次的课程。
4. 同一课程包含多组星期、节次或地点。
5. 小数学分。
6. 多位教师以及教师字段为空。
7. 上课说明、调课信息和考试信息为空。
8. 临时停课、补课和换教室。
9. “其他信息”中的期中考试，以及 `</br>`、`<br>`、`<br/>` 和真实换行变体。
10. 期中考试缺少地点、时间格式无效或“其他信息”为未知文本。
11. 接口返回 HTML、空字符串或缺少 `rows`。
12. 学期第一周日期不是周一时的校验和归一化。
